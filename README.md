## 🛠️ What I've Built
- 📱 **PurSuit** — Full-stack mobile career-discovery feed (React Native, Expo, Supabase) using on-screen Claude Vision and real-time cosine similarity trait-ranking.
- ☀️ **SolarSense** — Data-driven regional solar adoption platform with 3D geospatial mapping and serverless AWS pipelines *(UI/UX Track Winner @ DataHacks 2026)*
- 🧾 **CheckMate** — AI receipt-splitting app utilizing multimodal Gemini OCR and an autonomous Playwright browser agent for live menu verification.
- 🌐 **HKN Projects Portal** — Production engineering portal backed by Decap CMS and a sitewide vector RAG search assistant (Pinecone & Gemini).
- 🏄‍♂️ **Smartfin Firmware** — Low-power embedded C++ firmware and data acquisition drivers for coastal oceanographic research devices.
- 📊 **Enterprise Security Dashboard** — Power BI platform with custom star-schema models and SQL query tuning, cutting query latency by 87% at FedEx.
